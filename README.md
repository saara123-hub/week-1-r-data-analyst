# Week 1 – R Data Analyst Internship

## Project
Data Cleaning and Preliminary Analysis with R

## Dataset
Titanic Passenger Dataset (publicly available dataset).

## Contents
- `week1_titanic_analysis.R` – R analysis script
- `report/Week_1_R_Data_Analyst_Report.docx` – internship report
- `data/titanic.csv` – place the downloaded Titanic CSV here
- `figures/` – place exported charts here

## Analysis Performed
- Dataset inspection
- Missing-value handling
- Duplicate check
- Categorical encoding using factors
- Outlier inspection
- Min-max normalization
- Descriptive statistics
- Correlation analysis
- Exploratory visualizations

## How to Run
1. Put `titanic.csv` inside the `data` folder.
2. Open `week1_titanic_analysis.R` in RStudio.
3. Run the script section by section.
4. Save the generated charts/screenshots for the final submission.

## Note
The report is prepared for the Week 1 internship task and should be reviewed against the exact dataset file used before submission.
